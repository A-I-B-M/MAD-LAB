You need to make "Pomodoro Timer App"[Focus timer application]. This app will help you 
study in a focused way in short sprint. The feature are given below;

Features :
	25 minute focus timer [set it to 5 min for testing]
	5 minute break timer  [set it to 1 min for testing]
	Start/Pause/Reset buttons
	Automatic switching between focus and break
	Clean UI
	Works with Expo

Useful Libraries :
	npx expo install expo-notifications

	npm install @react-native-async-storage/async-storage

	
Imports you might need : 
  View,
  Text,
  TouchableOpacity,
  StyleSheet,
  StatusBar,
  useEffect,
  useState

Command to create project : 

npx create-expo-app student_id 		[you use the appropriate one from slide]
cd student_id
npm install				[optional. should already be set up]
npm start

[Hints you will need to use useEffect]
